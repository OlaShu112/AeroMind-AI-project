# AeroMind AI — Object Detection

## Overview
Object detection identifies objects within camera images
or video frames.

## Purpose
AeroMind AI aims to use computer vision to support
environmental awareness during simulated drone missions.

## Potential Objects
Depending on the detection model and its training data,
the system may identify:
- People
- Vehicles
- Buildings
- Trees
- Other visible objects

## Object Tracking
Object tracking attempts to maintain an object's
identity across consecutive video frames.

## Safety Limitations
Object detection can produce false positives,
false negatives and incorrect classifications.

Detection results alone must not authorise flight
movements or replace independently validated
collision-avoidance mechanisms.
